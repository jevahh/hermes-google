# hermes-google
Hermes — Google Calendar Assistant
This is a small personal bot that reminds you of your calendar events via Discord.

It helps you stay on top of upcoming exams and meetings by posting a one-line
reminder to your Discord channel before each event.

What it does

Reads your Google Calendar
Sends a reminder to a Discord channel before each event
Runs daily on a schedule


How it works

The app connects to your Google Calendar and Discord, then posts a short message
like "📅 Reminder (1 day): Exam — Sat 14 Nov 2026" to your Discord channel.

Privacy

We only read your calendar events to set reminders. See the Privacy Policy [blocked]
for details.

Use

This is a personal project. You can fork it or run it yourself.
